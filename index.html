How It Works

2. Prepare for Cut

Weld shapes, nest designs, set contours for print-and-cut, or create rhinestone templates. Select objects and adjust mats.

3. Connect and Cut

Link your cutter via USB, TCP, or wireless. Send jobs directly or save .PLT for offline. Preview and execute with precision.

4. Export and Iterate

Output to G-code, FCM, or images. Refine designs and repeat for flawless production.
